## Overview

Paste a URL and receive a structured accessibility analysis driven by Google Gemini. The app helps developers and QA engineers find inclusive-design issues early and export findings for remediation backlogs.

## Features

- URL-based page analysis
- AI-assisted WCAG / ADA / Section 508 oriented findings
- Actionable, developer-friendly report UI
- React 19 + Vite front end with typed services
